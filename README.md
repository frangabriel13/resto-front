# resto-front

Frontend de Clubsy (Next.js): tarjeta del cliente, panel del comercio y panel admin.

```bash
pnpm install
pnpm dev        # http://localhost:3002 (necesita la API en :3001)
```

Comandos, organización y producción (imagen de Docker para Coolify): ver `CLAUDE.md`. Variables de entorno: `.env.example`.
